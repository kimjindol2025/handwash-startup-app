# 손세차장 창업 준비 노트

책의 15개 단원을 실제 창업 준비 기록과 계산으로 연결하는 정적 웹 앱입니다.

## 실행

`index.html`을 브라우저에서 열면 바로 사용할 수 있습니다. 별도 서버나 패키지 설치가 필요하지 않습니다.

## 포함 기능

- 15개 단원 메뉴와 단원별 입력·체크리스트
- 후보지·건물·배수·폐수 사전 확인 기록
- 창업비 합계 계산, 서비스별 인건비·소모품비·공헌이익 계산
- 월 손익분기 매출과 하루 목표 계산
- 장비 점검·고장 기록, 예약·대기 운영, 분쟁 대응 기록
- 오픈 첫 달 점검과 분기별 운영 지표
- 입력 자동 저장, JSON 내려받기, 인쇄

## 데이터와 한계

입력 내용은 현재 브라우저의 `localStorage`에 저장됩니다. 다른 기기나 브라우저와 자동 동기화되지 않으므로 정기적으로 JSON 파일로 내려받아 보관하세요. 초기화는 저장된 기록을 삭제합니다.

계산은 사용자가 입력한 값에 따른 참고 결과입니다. 사업 수익을 보장하지 않으며, 인허가·건축·배수·폐수·세무·노무 사항은 관할 기관 및 전문가에게 확인해야 합니다.
