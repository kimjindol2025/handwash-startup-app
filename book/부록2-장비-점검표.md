# 부록 2. 장비 점검표

8단원 내용을 출력용으로 정리한 표입니다. 제조사 설명서와 설치업체 안내가 더 엄격하면 그 기준을 따릅니다. 전기함 개방이나 압력부 분해를 뜻하지 않습니다.

| 주기 | 확인 항목 | 확인 | 이상 내용·사진 | 점검자 |
| --- | --- | --- | --- | --- |
| 매일 개점 전 | 바닥 누수·물 고임, 호스·건·케이블 외관 손상, 이상 냄새·소음 | □ |  |  |
| 매일 영업 중 | 압력·흡입력·풍량 변화, 반복 정지, 세제 투입 변화 | □ |  |  |
| 매일 마감 후 | 장비 정리, 필터·흡입구 오염, 호스 정리, 영하 예보 시 동파 대비 | □ |  |  |
| 매주 | 필터·흡입구, 노즐·연결부 외관, 누수·누기 흔적, 배수 상태 | □ |  |  |
| 매월 | 고정 상태, 계기 변화, 반복 고장 추세, 전문가 점검 필요 여부 | □ |  |  |
| 계절 전후 | 동파 위험, 침수 흔적, 오래 쉰 뒤 재가동 조건 | □ |  |  |

**즉시 사용 중지 신호:** 연기, 불꽃, 타는 냄새, 반복 차단, 과열, 장비 내부 누수, 감전 느낌. 이때는 주변을 통제하고 긴급 안전 절차를 먼저 따른 뒤 전문가에게 연락합니다.
