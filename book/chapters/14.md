# 14단원 오픈 준비와 첫 달 운영

## 시작하며

오픈 날짜가 정해지면 마음이 급해집니다. 공사는 끝났고 장비도 들어왔으니 바로 손님을 받아야 할 것 같습니다. 하지만 손님을 받기 전에 작업 순서와 설비가 실제 현장에서 맞물리는지 확인해야 합니다. 시운전은 장비가 켜지는지 보는 절차가 아니라, 고객이 들어와 결제하고 차량을 맡기고 작업을 확인한 뒤 나가는 전체 과정을 점검하는 일입니다.

첫 달은 완벽한 운영을 보여주는 기간이 아닙니다. 계획한 방식이 현장에서도 작동하는지 확인하고, 안전·품질·대기·비용의 문제를 작게 고쳐 가는 기간입니다. 처음부터 무리하게 많은 고객을 받기보다, 감당할 수 있는 범위에서 기준을 세우는 편이 장기적으로 도움이 됩니다.

## 오픈 전 시운전: 장비보다 흐름을 확인한다

### 1. 시설과 안전을 확인한다

영업을 시작하기 전에 전기·급수·배수·폐수 처리와 각 장비의 설치 상태를 확인합니다. 점검과 시험은 설치 업체의 안내, 장비 설명서, 현장 안전 기준에 따라 진행합니다. 전기함을 열거나 고압 배관을 분해하는 작업은 운영자가 임의로 하지 않습니다.

- 장비별 전원 차단 위치와 비상 정지 방법을 직원이 알고 있는가?

- 누수·진동·이상 소음·타는 냄새가 없는가?

- 바닥 물이 고이거나 고객 통로로 흐르지 않는가?

- 배수구와 작업 구역이 막히지 않았는가?

- 세제와 소모품이 표시·보관 기준에 맞게 정리되어 있는가?

- 미끄럼, 호스 걸림, 차량 이동 중 충돌 위험을 줄였는가?

### 2. 실제 차량으로 전 과정을 시험한다

가능하다면 직원 차량이나 사전 동의를 받은 차량으로 접수부터 출고까지 연습합니다. 작업 항목을 하나씩 확인하고, 예상 시간과 실제 시간을 기록합니다.

1. 예약 또는 현장 접수

2. 차량과 고객 요청 사항 확인

3. 작업 범위·가격·예상 시간 안내

4. 차량 이동과 대기 위치 안내

5. 작업 수행

6. 완료 검수와 추가 작업 확인

7. 결제·출고 안내

8. 작업 공간 정리와 다음 차량 준비

연습 중에는 일부러 질문을 던져 봅니다. 고객이 “이 얼룩도 지워지나요?”라고 물으면 누가 어떤 기준으로 답할지, 예약 시간이 겹치면 어떻게 조정할지, 장비가 멈추면 누구에게 보고할지 정합니다. 모든 예외를 미리 해결할 수는 없지만, 누구에게 알려야 하는지는 정해둘 수 있습니다.

## 직원 동선과 역할을 맞춘다

작업 공간에 여러 사람이 들어오면 이동 경로가 겹칠 수 있습니다. 차량 이동 동선, 작업자 이동 동선, 고객 대기 동선을 구분해 보십시오. 호스와 전선이 통로를 가로지르지 않도록 정리하고, 젖은 바닥을 지나는 경로와 고객이 서 있을 위치를 확인합니다.

직원마다 “알아서 하라”고 맡기기보다 접수·작업·검수·출고의 책임자를 분명히 합니다. 소규모 매장에서는 한 사람이 여러 역할을 맡을 수 있지만, 업무가 누락되지 않도록 각 단계의 담당은 정해야 합니다.

| 단계 | 확인할 책임 | 기록할 내용 |
| --- | --- | --- |
| 접수 | 고객 요청과 차량 상태 확인 | 작업 항목, 특이 사항, 예상 시간 |
| 작업 배정 | 순서와 담당자 결정 | 시작 시각, 담당자 |
| 작업 | 약속된 범위에 맞춰 수행 | 추가 요청, 작업 중 발견 사항 |
| 검수 | 완료 기준과 누락 확인 | 재작업 여부, 확인자 |
| 출고 | 결과와 주의 사항 안내 | 결제, 인계 시각, 고객 확인 |

## 첫 달 작업 시간을 측정한다

가격표와 예약 간격은 예상만으로 정하면 실제 운영과 어긋날 수 있습니다. 서비스별로 접수부터 출고까지 걸린 시간을 기록합니다. 작업 자체의 시간뿐 아니라 차량 이동, 고객 설명, 결제, 정리 시간도 포함해야 합니다.

| 날짜 | 서비스 | 작업자 수 | 접수 | 작업 시작 | 출고 | 접수~출고 시간 | 사람별 투입 시간 | 재작업·대기 이유 |
| --- | --- | ---: | --- | --- | --- | ---: | --- | --- |
|  |  |  |  |  |  |  |  |  |

접수~출고 시간은 고객의 체류 시간입니다. 9단원의 인건비 계산에는 별도로 기록한 사람별 투입 시간을 사용합니다.

기록은 직원의 속도를 감시하려는 자료가 아닙니다. 약속한 시간에 맞는 예약 간격인지, 어느 공정에서 대기가 생기는지, 서비스 범위가 모호해 시간이 늘어나는지 찾기 위한 자료입니다. 차량 크기와 오염 상태가 다르면 단순 평균으로 판단하지 말고 조건도 함께 기록합니다.

## 오픈 초기 고객 응대

처음 방문한 고객은 매장의 작업 방식과 기준을 모릅니다. 접수할 때 작업 범위, 제외되는 항목, 추가 비용이 생기는 조건, 예상 완료 시각을 짧고 분명하게 설명합니다. 고객이 원하는 결과가 작업 범위를 넘어서는 경우에는 가능 여부를 확인한 뒤 약속합니다.

대기가 생기면 이유와 예상 시간을 먼저 알립니다. “곧 됩니다”라고 반복하기보다 현재 상황을 설명하고, 고객이 선택할 수 있는 대안을 안내합니다. 약속한 시간이 바뀌면 고객이 먼저 묻기 전에 알려주는 것이 신뢰를 지키는 데 도움이 됩니다.

## 매일 기록하고 주 단위로 고친다

첫 한 달 동안에는 매일 짧게 마감 기록을 남깁니다.

- 방문 차량 수와 서비스별 작업 수

- 예약 고객과 현장 방문 고객 수

- 평균 작업 시간과 대기 시간

- 재작업·환불·고객 불만의 내용과 처리 결과

- 장비 이상과 사용 중지 시간

- 소모품 사용량과 부족 품목

- 당일 매출과 결제 수단별 정산 차이

- 다음 영업일에 확인할 사항

문제가 생기면 사람을 탓하기 전에 조건을 확인합니다. 안내 문구가 없었는지, 작업 기준이 서로 달랐는지, 예약 간격이 짧았는지, 설비나 도구가 부족했는지 살펴봅니다. 개선 사항은 담당자와 확인 날짜를 함께 적고, 실제로 나아졌는지 다시 확인합니다.

| 발견한 문제 | 원인으로 추정한 점 | 바꿀 내용 | 담당자 | 확인 날짜 | 결과 |
| --- | --- | --- | --- | --- | --- |
|  |  |  |  |  |  |

## 첫 달 운영에서 지킬 원칙

첫 달 매출을 높이려고 수용 능력보다 많은 예약을 받으면 작업 지연과 품질 저하가 한꺼번에 나타날 수 있습니다. 한 번에 바꿀 항목을 너무 많이 늘리지 말고, 안전과 법적·시설 기준을 우선 확인합니다. 매출이 기대보다 낮더라도 할인만 반복하기 전에 유입 경로, 재방문, 서비스별 작업 시간과 실제 남는 금액을 나누어 봅니다.

현장 조건이나 관할 기준에 따라 필요한 확인이 달라질 수 있습니다. 인허가, 배수, 오수 처리, 안전 관련 사항은 오픈 직전 추측으로 판단하지 말고 관할 부서와 해당 전문가에게 확인합니다.

## 다음 단원으로
