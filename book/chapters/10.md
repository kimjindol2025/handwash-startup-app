# 10단원 매출과 손익을 직접 계산하기

## 시작하며

손세차장 매출은 “하루에 몇 대를 받을 수 있을까?”만으로 계산되지 않습니다. 하루 작업 대수와 서비스별 가격, 실제 작업 시간, 영업일수, 건당 변동비, 월 고정비를 함께 봐야 합니다. 매출이 커도 비용이 더 크면 손실이 나고, 작업량이 늘어도 인력이나 공간이 부족하면 계획한 대수를 처리하지 못할 수 있습니다.

이 단원은 특정 세차장의 매출이나 수익을 예측하지 않습니다. 독자가 자신의 가격표와 운영 계획, 견적, 생활비를 넣어 손익을 계산하도록 돕습니다.

## 매출과 이익은 다르다

- **매출**은 고객에게 서비스를 제공하고 받은 금액의 합계입니다.

- **변동비**는 차량을 한 대 더 작업할 때 함께 늘어나는 인건비·세제·소모품비·결제비용 등입니다.

- **공헌이익**은 매출에서 변동비를 뺀 금액입니다. 월 고정비를 감당하는 데 쓰입니다.

- **월 영업 손익**은 월 공헌이익에서 월 고정비를 뺀 금액입니다.

- 사업주 생활비, 세금, 대출 원금·이자 등은 회계상 분류와 별개로 실제 현금흐름에 포함해 확인해야 합니다.

인건비는 지급 방식에 따라 분류합니다. 작업량과 관계없이 지급하는 월급은 고정비에, 작업 증가에 따라 추가 발생하는 건별 인건비는 변동비에 넣습니다. 9단원처럼 가격 검토를 위해 월급이나 사업주 노동을 건당 배분했다면, 월 손익 계산 때 같은 금액을 고정비에 다시 더하지 않습니다. 사업주의 가정 보수와 실제 현금 인출도 구분해 기록합니다.

매출과 비용은 부가세 포함·제외 기준을 통일해 계산합니다. 아래 표는 운영 판단용 단순 손익표이며, 금융비용·세금까지 넣었다면 회계상 영업손익과 구분해 표시합니다.

가격표에서 건당 공헌이익을 계산했다면, 이번에는 한 달의 작업량을 넣어 전체 사업에 연결합니다.

## 하루 매출을 계산하는 순서

서비스 종류가 하나라면 다음 계산으로 시작할 수 있습니다.

**하루 매출 = 하루 작업 대수 × 평균 객단가**

서비스 종류가 여러 개라면 서비스별로 계산합니다.

**하루 매출 = Σ(서비스별 작업 대수 × 서비스별 가격)**

이 책의 평균 객단가는 전체 서비스 매출을 작업 차량 대수로 나눈 값입니다. 추가 서비스는 해당 차량의 매출에 합치고, 분할 결제나 추가 결제를 차량 수에 다시 세지 않습니다. 단순히 가장 비싼 서비스 가격을 객단가로 넣지 않습니다. 기본 세차와 추가 서비스를 실제로 어느 정도 선택하는지에 따라 평균이 달라집니다.

### 계산 예시

아래 값은 계산 순서를 설명하기 위한 가정입니다. 실제 매출이나 업계 평균이 아닙니다.

- 하루 작업: 8대

- 평균 객단가: 45,000원

- 월 영업일: 26일

계산하면:

- 하루 매출 = 8대 × 45,000원 = 360,000원

- 월 매출 = 360,000원 × 26일 = 9,360,000원

이 금액은 매출입니다. 여기서 작업자 인건비, 세제와 소모품, 결제 비용, 임대료와 공과금 등을 빼기 전이므로 사업주에게 남는 돈으로 보면 안 됩니다.

## 처리 가능한 작업량을 먼저 확인하기

하루 작업 대수는 희망 목표가 아니라 실제 운영 능력으로 제한됩니다. 서비스별 작업 시간이 다르고, 접수·차량 이동·정리·검수에도 시간이 듭니다.

다음 조건을 함께 검토합니다.

- 서비스별 평균 작업 시간과 사람별 투입 시간

- 동시에 작업할 수 있는 차량 수와 안전한 이동 공간

- 직원 수와 교대·휴게 시간

- 특정 시간대에 몰리는 예약과 현장 방문

- 개점 준비와 마감 업무

- 비·추위·더위 등 날씨에 따른 작업 속도 변화

- 장비 고장이나 재작업이 생겼을 때 줄어드는 처리량

한 사람이 1시간 걸리는 서비스를 하루 8시간 영업한다고 해서 하루 8대를 반드시 처리할 수 있는 것은 아닙니다. 준비와 정리, 접수와 출고, 휴게시간, 지연이 있기 때문입니다. 작업표를 만들어 실제로 하루 흐름에 배치해 봐야 합니다.

## 월 공헌이익과 손익분기점

서비스별 변동비를 빼면 건당 공헌이익이 나옵니다. 서비스가 여러 개일 때에는 서비스별 비중을 고려해 평균 공헌이익을 구합니다.

**월 공헌이익 = 월 매출 − 월 변동비**

**월 영업 손익 = 월 공헌이익 − 월 고정비**

단일 서비스만 있다고 가정하면 손익분기 작업 대수는 다음과 같이 계산할 수 있습니다.

**월 손익분기 작업 대수 = 월 고정비 ÷ 건당 공헌이익**

건당 공헌이익이 양수일 때 사용하는 식입니다. 0 이하라면 이 식으로 유한한 손익분기 대수를 구할 수 없습니다. 월 필요 대수가 소수이면 올림하고, 여러 서비스의 평균은 예상 판매 비중으로 가중합니다.

### 계산 예시

9단원의 계산법을 적용하되 판매가와 변동비는 별도로 설정한 가정 예시입니다.

- 평균 객단가: 45,000원

- 건당 변동비: 18,000원

- 건당 공헌이익: 27,000원

- 월 고정비: 5,400,000원

- 월 영업일: 26일

손익분기 작업 대수는:

- 월 기준 = 5,400,000원 ÷ 27,000원 = 200대

- 하루 기준 = 200대 ÷ 26일 ≈ 하루 7.7대

이 조건에서는 하루 평균 약 7.7대를 작업해야 월 고정비와 공헌이익이 같아집니다. 이 숫자는 사업주의 보수, 세금, 대출 원금·이자 등 빠진 항목이 있으면 달라집니다. 실제 계산표에 포함한 비용이 무엇인지 명확히 적어야 합니다.

## 매출이 예상보다 낮을 때도 계산하기

계획은 한 가지 숫자만으로 세우지 않습니다. 기본 시나리오와 낮은 매출 시나리오를 함께 계산해 봅니다. 낮은 시나리오의 매출을 임의로 “안전한 숫자”라고 부르지 말고, 왜 그 숫자를 넣었는지 근거를 기록합니다.

| 시나리오 | 하루 작업 대수 | 평균 객단가 | 월 영업일 | 월 매출 | 월 손익 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 낮은 매출 가정 |  |  |  |  |  |
| 기본 계획 |  |  |  |  |  |
| 높은 작업량 가정 |  |  |  |  |  |

낮은 매출에서도 임대료와 인건비, 생활비를 감당할 수 있는지 확인합니다. 감당하기 어렵다면 고정비를 낮추거나, 인력과 영업시간을 조정하거나, 계약·개업 시기를 다시 검토해야 할 수 있습니다.

## 현금흐름도 따로 본다

월 손익이 흑자라고 통장에 돈이 충분하다는 뜻은 아닙니다. 보증금·장비비·공사비는 한 번에 큰 현금 지출이 생길 수 있고, 매출 입금 시점과 임대료·급여 지급 시점이 다를 수 있습니다. 대출 원금 상환은 손익계산과 현금흐름에서 다르게 보일 수 있습니다.

월별로 다음을 적어 봅니다.

- 월초 현금 잔액

- 매출 입금 예상일과 금액

- 임대료·급여·공과금 지급일

- 소모품 구매와 장비 수리 예상액

- 세금·보험·대출 상환일

- 월말 예상 잔액과 필요한 최소 운영자금

몇 달 동안 현금 잔액이 계속 줄어드는 계획이라면, 손익분기점에 도달하기 전까지 버틸 자금이 있는지 다시 확인해야 합니다.

## 숫자를 검토할 때 자주 생기는 착각

### 하루 최대 처리량을 매일의 평균으로 쓰는 것

가장 바쁜 날의 작업량을 매일 반복할 수 있다고 가정하면 매출이 과대 계산될 수 있습니다. 평일·주말과 시간대를 나누어 관찰하고, 준비·마감 시간도 반영합니다.

### 평균 객단가를 최고 가격으로 잡는 것

고객이 모두 패키지나 추가 서비스를 선택한다고 가정하지 않습니다. 실제 판매 비중이 확인되기 전에는 여러 가격대의 비중을 나누어 시나리오를 만듭니다.

### 사업주 노동을 무료로 계산하는 것

사업주가 현장에서 일하는 시간도 기록합니다. 생활비를 가져가지 못하는 구조를 이익이 나는 사업으로 착각하지 않도록, 사업주 보수 전·후의 숫자를 구분해 봅니다.

### 비용이 빠진 채 흑자라고 결론 내리는 것

세금·보험·수리·휴무·재작업·대출 상환 등 어떤 비용을 포함했고 제외했는지 표에 적습니다. 계산 결과에는 그 전제를 함께 둡니다.

## 이 단원 요약

- 매출과 이익은 다르며, 처리 가능한 작업량부터 확인합니다.
