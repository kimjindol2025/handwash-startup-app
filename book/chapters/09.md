# 9단원 서비스와 가격표 만들기

## 시작하며

서비스별 가격은 주변 시세만 보고 정하기 어렵습니다. 같은 금액을 받아도 작업 시간, 작업자 수, 세제와 소모품 사용량이 다르면 실제로 남는 돈은 달라집니다. 먼저 고객에게 제공할 작업 범위를 정하고 실제 투입 시간을 잰 뒤, 인건비와 건당 비용을 빼서 서비스별 손익을 계산해야 합니다.

이 단원은 가격을 정답처럼 제시하지 않습니다. 사업주가 자신의 작업 시간과 인건비, 소모품비를 넣어 가격표를 판단하도록 돕습니다.

## 가격표는 고객과 매장의 약속이다

고객이 가격표를 보고 “이 금액에 어디까지 해주나요?”라고 물을 때 답이 분명하지 않으면 작업 전 기대가 서로 달라집니다. 차량 상태를 본 뒤 추가 작업이 필요해도 기준이 없으면 고객에게 설명하기 어렵고, 직원마다 작업 범위와 요금 안내가 달라질 수 있습니다.

가격표에는 금액뿐 아니라 작업 범위, 제외되는 작업, 추가 요금이 생기는 조건, 예상 소요 시간을 함께 정리해야 합니다. 차량 크기나 오염도에 따라 달라지는 항목은 작업 전에 고객에게 설명하고 동의를 받습니다.

> **가격은 고객을 부르는 숫자인 동시에, 약속한 작업을 책임질 기준이다.**

## 서비스별 작업 범위부터 정한다

서비스마다 실제 작업을 적습니다. “깨끗하게 세차”처럼 해석이 넓은 표현 대신 작업자가 수행할 공정을 구체화합니다.

심한 오염, 반려동물 털, 차량 내부 짐, 특수 소재나 추가 손질은 기본 범위와 어떻게 다른지 사전에 안내합니다. 추가 요금이 필요한 경우에는 고객에게 차량 상태와 작업 내용을 설명하고 동의를 받은 뒤 시작합니다.

## 작업 시간을 실제로 잰다

작업 시간은 기억이나 희망 처리량으로 정하지 않습니다. 접수 후 준비, 실제 작업, 정리, 검수까지 가능한 범위에서 여러 차량의 시간을 기록합니다. 차량 크기와 오염도, 실내 짐처럼 작업 시간이 달라지는 조건도 함께 적습니다.

차량이 매장에 머문 시간만 재면 작업자가 준비하거나 마감하는 시간이 빠질 수 있습니다. 실제 사람의 투입 시간을 기준으로 계산해야 인건비와 처리량을 올바르게 볼 수 있습니다.

## 서비스 한 건의 변동비 계산

서비스에 직접 들어가는 비용을 먼저 계산합니다.

- 직접 인건비: 작업자 수와 사람별 투입 시간에 따른 인건비

- 소모품비: 세제, 타월 세탁, 장갑, 브러시 등 해당 작업에 사용한 비용

- 결제 수수료 등 건별 비용

- 그 밖에 해당 작업에 직접 들어가는 비용

사업주가 직접 일하더라도 인건비를 0원으로 두지 않는 것이 좋습니다. 사업주가 투입한 시간이 비용으로 보이지 않으면, 매출은 있지만 본인에게 남는 돈이 없는 구조를 수익성 있는 사업으로 오해할 수 있습니다.

**직접 인건비 = 작업자 수 × (1인당 작업 시간 ÷ 60) × 시간당 인건비**

**건당 공헌이익 = 서비스 판매가격 − 건당 변동비**

건당 공헌이익은 순이익이 아닙니다. 이 금액으로 월세·관리비·보험·통신비·세금·대출이자와 장비 비용 등 고정비를 부담해야 합니다.

### 계산 예시

다음은 계산 방법을 보여주기 위한 가정값이며, 실제 시장가격이나 권장 가격이 아닙니다.

- 서비스 판매가격: 50,000원

- 작업자 1명, 작업시간: 60분

- 시간당 인건비 가정: 15,000원

- 세제·타월 세탁 등 소모품비: 3,000원

- 결제 수수료와 기타 건별 비용: 1,000원

직접 인건비는 15,000원, 건당 변동비 합계는 19,000원입니다.

**건당 공헌이익 = 50,000원 − 19,000원 = 31,000원**

31,000원이 순이익이라는 뜻은 아닙니다. 이 금액에서 매장의 월 고정비를 부담해야 합니다. 작업이 60분에서 90분으로 늘거나 추가 작업자가 필요하면 인건비도 달라집니다. 실제 작업 기록을 보고 가격·작업 범위·예약 간격 중 무엇을 조정할지 판단해야 합니다.

## 가격표에 안내할 내용

- 차량 크기별 가격과 기준

- 기본 가격에 포함되는 작업과 제외되는 작업

- 심한 오염이나 추가 시간이 필요한 경우의 안내

- 추가 작업을 시작하기 전 고객 동의를 받는 절차

- 서비스별 예상 소요 시간의 안내 기준

- 예약 고객과 현장 방문 고객의 접수 방식

- 재작업이나 불만이 있을 때 확인하고 결정할 담당자

- 가격을 변경할 때 기존 예약과 고객에게 안내할 방법

고객이 읽는 가격표는 간결하게 만들고, 직원에게는 서비스별 작업 순서와 확인 기준을 별도 문서로 제공합니다. 가격표와 실제 작업 기준이 다르면 고객 불만과 직원 혼선이 생길 수 있습니다.

## 가격을 정할 때 흔한 착각

### 주변보다 싸면 손님이 늘 것이라는 생각

낮은 가격은 방문을 늘릴 수 있지만, 작업 시간이 길고 변동비가 크면 바쁠수록 손해가 커질 수 있습니다. 가격을 낮추기 전에 건당 공헌이익과 실제 처리 가능 대수를 확인합니다.

### 사업주가 일하니 인건비가 없다는 생각

사업주가 투입한 시간도 사업의 자원입니다. 사업주 인건비를 빼면 본인의 보수와 직원 고용 비용을 비교할 수 없습니다.

### 추가 작업을 계속해도 가격은 그대로라는 생각

추가 서비스가 반복되면 작업 시간과 비용이 달라집니다. 작업 범위를 조정하거나, 사전에 추가 요금을 안내하거나, 해당 서비스 가격을 다시 계산해야 합니다.

### 매출과 남는 돈을 같은 것으로 보는 생각

하루 매출이 높아도 인건비와 소모품비를 빼면 건당 남는 금액이 작을 수 있습니다. 서비스별 공헌이익을 월 고정비와 연결해야 합니다.

## 가격을 다시 살펴볼 때

가격을 무조건 자주 바꾸기보다 실제 비용과 운영 조건이 변했을 때 근거를 갖고 검토합니다.

- 소모품 구매 가격이 바뀌었을 때

- 인건비나 근무 방식이 바뀌었을 때

- 평균 작업 시간이 늘거나 줄었을 때

- 추가 작업 요청이 반복되는데 요금 기준이 없을 때

- 재작업과 고객 대기가 특정 서비스에 몰릴 때

- 장비나 시설 변경으로 작업 흐름이 달라졌을 때

변경 전후 가격, 작업 범위, 원가 계산, 고객 안내 시점을 기록하면 가격을 조정한 이유를 설명할 수 있습니다.

2. 작업 범위가 분명하지 않아 고객과 직원 사이에 오해가 생긴 사례는 무엇입니까?

3. 서비스별 작업시간과 소모품 사용량을 기록해야 하는 이유를 보여주는 현장 사례가 있습니까?

## 이 단원 요약

- 서비스별 작업 범위를 정하고 실제 작업 시간을 잽니다.

- 판매가에서 인건비와 소모품비를 빼 건당 남는 돈을 계산합니다.

- 사업주 인건비를 0원으로 두지 않습니다.
