# 8단원 장비 고장과 관리

## 시작하며

장비는 영업을 돕지만, 고장이 나면 작업과 고객 응대가 함께 흔들립니다. 고장 순간에 중요한 것은 무리하게 작동을 되살리는 일이 아닙니다. 사람과 차량을 안전하게 보호하고, 추가 손상을 막고, 수리 판단에 필요한 정보를 남기는 것입니다.

장비 관리가 잘되는 사업장은 고장이 전혀 없는 곳이 아닙니다. 평소 정상 상태를 알고 이상을 빨리 알아차리며, 작업자가 할 수 있는 조치와 전문가에게 맡겨야 할 작업을 구분하는 곳입니다. 고장 기록이 쌓이면 수리와 교체, 예비 장비 중 무엇이 더 합리적인지도 판단할 수 있습니다.

## 현장 장면

영업이 바쁜 시간에 고압세척기의 압력이 갑자기 떨어지거나, 진공청소기의 흡입력이 약해지면 직원은 작업을 계속하고 싶어집니다. 차가 밀리고 고객이 기다리기 때문입니다. 하지만 원인을 모른 채 장비를 반복해서 켜거나, 압력 배관을 임의로 풀거나, 차단기를 계속 올리면 고장과 위험이 더 커질 수 있습니다.

이때 운영자가 먼저 해야 할 일은 장비를 안전하게 멈추고 주변을 통제하는 것입니다. 어느 장비에서 어떤 증상이 언제 시작됐는지, 그 직전 어떤 작업을 했는지 기록하고 수리업체에 전달합니다. 이 기록이 정확하면 점검 범위를 좁히고 불필요한 재방문과 영업 중단을 줄이는 데 도움이 됩니다.

## 저자의 한 문장

> 고장을 잘 관리한다는 것은 억지로 계속 돌리는 것이 아니라, 이상을 알아채고 안전하게 멈추는 것이다.

## 경험에서 얻은 판단

장비 관리는 개업 전 시운전에서 시작됩니다. 새 장비든 기존 장비든 정상일 때의 소리, 압력, 흡입력, 풍량, 물 흐름을 확인하고 기록해야 이상을 구별할 수 있습니다.

### 개업 전 설치·시운전 확인

- 장비명·모델명·제조번호·설치일·보증 기간을 기록합니다.

- 전원과 배관 연결, 장비 고정이 계약된 설치 범위와 맞는지 확인합니다.

- 작동 전·중·후의 누수, 이상 진동, 소음, 냄새를 확인합니다.

- 고압세척기는 압력 표시와 호스·건·커플러 상태를 확인합니다.

- 진공청소기는 호스·필터·흡입구와 모터 소리를 확인합니다.

- 에어·드라잉 장비는 압력·풍량·열·진동과 안전커버 상태를 확인합니다.

- 세제 투입 장치는 약품 종류와 희석 방식, 흡입·토출 상태를 확인합니다.

- 정상 작동 영상과 계기판 사진, 사용 설명서와 수리 연락처를 보관합니다.

- 작업자에게 정상 종료 방법과 즉시 사용을 중지해야 할 신호를 교육합니다.

시운전에서 문제가 나오면 구두로만 넘기지 않습니다. 발견 항목, 조치 담당자, 완료 기한을 적고, 조치 뒤 같은 조건으로 다시 작동시켜 확인합니다.

## 매일·매주·매월 점검표

점검 주기는 장비 제조사의 사용 설명서와 설치업체 안내를 우선합니다. 아래 표는 현장 운영자가 외관과 정상 동작을 살피는 기본 틀입니다. 전기함 개방이나 압력부 분해를 뜻하지 않습니다.

| 주기 | 확인 항목 | 기록 |
| --- | --- | --- |
| 매일 개점 전 | 바닥 누수·물 고임, 호스·건·케이블의 외관 손상, 이상 냄새·소음 | 정상/이상, 위치, 사진 |
| 매일 영업 중 | 압력·흡입력·풍량의 변화, 반복 정지, 세제 투입 변화 | 시각, 장비, 증상, 작업 영향 |
| 매일 마감 후 | 장비 정리, 설명서가 허용한 필터·흡입구의 눈에 보이는 오염 확인, 호스 정리 | 정리 여부, 전달 사항 |
| 매주 | 필터·흡입구, 노즐과 연결부의 외관, 누수·누기 흔적, 배수 상태 | 이상 부위와 조치 |
| 매월 | 고정 상태, 계기 변화, 반복 고장 추세, 전문가 점검 필요 여부 | 점검자, 조치·예정일 |
| 계절 전후 | 동파 위험, 침수 흔적, 장시간 미사용 뒤 재가동 조건 | 예방 조치, 확인 결과 |

점검표에 “정상”만 표시하지 말고 평소와 다른 점을 적습니다. 이상이 반복되는데도 매번 같은 항목으로만 기록하면 교체와 수리의 근거가 남지 않습니다.

## 증상별 초동 대응

초동 대응은 현장 수리가 아니라 안전 확보와 진단 정보 수집입니다. 공통으로 장비를 멈추고 고객이 접근하지 않도록 안내한 뒤, 설명서에서 사용자 점검으로 허용한 범위만 확인합니다.

### 전원이 꺼지거나 차단기가 반복해서 내려갈 때

1. 해당 장비 사용을 중지하고 고객·직원의 접근을 막습니다.

2. 물기, 타는 냄새, 연기, 스파크, 비정상 열이 있으면 재가동하지 않습니다.

3. 젖은 손으로 플러그·차단기·전기함을 만지지 않습니다.

4. 내부 배선이나 부품을 열지 말고 전기 전문가 또는 수리업체에 연락합니다.

5. 발생 시각, 사용 중이던 기능, 반복 여부를 기록합니다.

원인을 모르는 상태에서 차단기를 반복해서 올리지 않습니다. 연기·불꽃·감전 위험이 보이면 주변을 통제하고 긴급 안전 절차를 우선합니다.

### 고압세척기 압력이 약하거나 맥동할 때

- 외부에서 급수 밸브와 물 공급 상태를 확인합니다.

- 호스가 꺾이거나 눌리지 않았는지, 외부 누수가 있는지 살핍니다.

- 사용자 설명서가 허용하는 범위에서 노즐 외관의 막힘을 확인합니다.

- 압력 조절부·펌프·고압 배관을 임의로 분해하거나 조정하지 않습니다.

- 압력 표시, 맥동 여부, 작동 시간, 물 공급 상태를 업체에 전달합니다.

고압 장비는 정지 후에도 압력이 남아 있을 수 있습니다. 안전하게 압력이 해소됐는지 모르면 연결부를 풀지 않습니다.

### 누수가 보일 때

- 물이 전기 설비나 통로로 번지지 않도록 주변을 통제합니다.

- 장비를 정상 정지하고 누수 위치와 상태를 사진으로 기록합니다.

- 외부 호스인지, 연결부 주변인지, 장비 내부인지 외관으로 확인되는 범위만 적습니다.

- 연결부를 무리하게 조이거나 임시 접착으로 막아 영업을 이어가지 않습니다.

- 고압 누수 또는 장비 내부 누수는 수리업체에 맡깁니다.

### 진공청소기 흡입력이 약할 때

- 고객 사용을 잠시 멈추고 호스 입구의 큰 이물질을 안전하게 제거합니다.

- 설명서에서 허용하는 필터 청소와 먼지통 비우기를 확인합니다.

- 호스 꺾임과 필터의 장착 상태를 확인합니다.

- 타는 냄새, 과열, 모터 소리의 급격한 변화, 반복 정지가 있으면 사용을 중지합니다.

- 모터와 전기 부품을 열지 말고 수리를 요청합니다.

### 건조 장비 풍량이나 온도가 달라졌을 때

- 장비를 정지하고 외부 흡입구·토출구가 막혔는지 확인합니다.

- 환기 공간과 주변의 이물질을 살핍니다.

- 과열 흔적, 이상 냄새, 반복 정지 여부를 기록합니다.

- 열선·모터·배선·보호장치를 분해하거나 우회하지 않습니다.

- 표시값, 작동 시간, 주변 조건과 정지 여부를 업체에 전달합니다.

## 직접 확인할 범위와 전문가 호출 기준

운영자와 작업자는 관찰, 기록, 주변 통제, 정상 정지, 설명서에 명시된 간단한 사용자 관리까지 맡습니다. 다음은 자격과 장비를 갖춘 전문가에게 요청합니다.

- 전기함 개방, 배선·차단기·접지 수리

- 고압 펌프·압력 조절부·압력 배관 분해

- 모터·콘덴서·기판·열선 교체

- 안전장치 우회나 규격을 확인하지 않은 부품 교체

- 장비 내부 누수, 연기, 스파크, 타는 냄새, 반복 과열의 원인 진단

- 전기 또는 압력 위험이 있는 상태에서의 시험 작동

원인이 확인되지 않은 반복 차단·정지·과열·압력 이상은 사용을 중지합니다. “한 번만 더 켜보자”는 판단이 고장 범위를 키울 수 있습니다.

## 수리비와 영업 중단 손실을 함께 보기

수리비만 보면 고장을 감수하고 계속 운영하는 편이 싸 보일 수 있습니다. 반대로 새 장비 가격만 보고 교체를 서두르면 기존 장비의 수리 가능성을 놓칠 수 있습니다. 판단할 때는 수리비와 함께 정지 시간, 못 받은 작업, 환불·재작업, 부품 수급 기간을 봅니다.

**고장 1회의 예상 손실 = 수리비 + 출장·부품비 + 중단 시간의 공헌이익 손실 + 재작업·환불 등 추가 비용**

중단 손실은 매출 전부가 아닙니다. 그 시간에 실제로 받을 수 있었던 작업의 매출에서, 작업을 하지 않아 아낀 재료비 등 변동비를 뺀 금액으로 계산합니다.

예를 들어 장비가 멈춰 작업 네 건을 받지 못했고, 각 작업에서 변동비를 뺀 금액이 2만 원이었다면 해당 시간의 공헌이익 손실은 8만 원입니다. 여기에 실제 수리비와 출장비, 지연으로 생긴 환불·재작업 비용이 있다면 더합니다. 이 숫자는 계산 방식 예시이므로 실제 작업 단가와 변동비를 넣어야 합니다.

수리와 교체를 비교할 때에는 다음을 함께 기록합니다.

- 최근 같은 증상의 발생 횟수

- 고장 1회당 평균 영업 중단 시간

- 부품 주문과 재방문까지 필요한 기간

- 수리 후 보증 범위와 기간

- 교체 시 철거·운반·설치·연결 공사 비용

- 다른 장비나 작업 방식으로 대체 운영할 수 있는 범위

## 수리업체에 정확히 전달하기

“장비가 안 됩니다”라는 말보다 증상과 발생 조건을 함께 전달하면 원인을 좁히는 데 도움이 됩니다.

### 수리 요청 기록 양식

```text
사업장과 담당자:
장비명·모델명·제조번호:
설치일 또는 사용 기간:
증상 최초 발생 시각:
어떤 작업 중 발생했는지:
정상 상태와 달라진 점:
소리·냄새·누수·계기 표시:
전원 또는 압력 차단 여부:
최근 수리·부품 교체 이력:
현재 사용 중지 여부:
사진·영상:
영업에 미치는 영향과 희망 방문 시간:
```

### 견적과 작업 확인

- 출장비·진단비·부품비·공임을 구분해 받습니다.

- 수리 전에 원인, 예정 작업, 예상 비용, 추가 승인 기준을 확인합니다.

- 추가 작업은 사전 연락과 승인 후 진행하도록 요청합니다.

- 교체 부품과 실제 작업 내용을 기록합니다.

- 수리 후 시험 조건과 결과, 보증 범위를 확인합니다.

- 수리 내역서를 받고 장비 이력에 반영합니다.

- 같은 증상이 재발하면 이전 접수와 작업 기록을 함께 전달합니다.

## 예비품과 고장 기록

모든 부품을 미리 사두기보다 고장 시 영업 영향이 큰 장비와 조달 시간이 긴 부품부터 파악합니다. 예비품 가격과 보관 기간, 호환 위험을 확인하고 실제로 필요한 최소 수량만 정합니다.

| 발생일 | 장비 | 증상 | 정지 시간 | 조치·교체 부품 | 비용 | 재발 여부 |
| --- | --- | --- | ---: | --- | ---: | --- |
|  |  |  |  |  |  |  |

기록이 쌓이면 어떤 장비가 반복해서 멈추는지, 수리가 길어지는 이유가 부품인지 출장 일정인지 알 수 있습니다. 그 자료를 다음 장비 선택과 유지관리 예산, 예비 장비 결정에 반영합니다.

- 수리업체가 증상을 진단하는 데 필요한 사진·영상·이력을 남길 수 있는가?

- 수리와 교체를 결정할 기준, 예비 장비가 필요한 장비를 구분했는가?

## 저자 현장 사례를 보태기 위한 질문

1. 고장 증상만 듣고 예상한 원인과 실제 현장 원인이 달랐던 사례가 있습니까? 원인을 찾는 데 어떤 정보가 도움이 됐습니까?

2. 사용자가 직접 손대면 위험하거나 고장을 키우기 쉬운 장비·부위는 무엇입니까?

3. 점검과 기록을 꾸준히 해서 영업 중단이나 재방문을 줄인 현장이 있습니까? 어떤 관리 습관이 효과적이었습니까?
