# 6단원 창업비용과 견적서 읽기

## 시작하며

세차장 창업비용을 알아볼 때 장비 가격부터 비교하는 경우가 많습니다. 하지만 장비를 사는 비용과 영업을 시작할 수 있는 상태를 만드는 비용은 다릅니다. 철거와 바닥 공사, 배수·급수·전기 작업, 운반·설치·시운전, 인허가 관련 검토, 개업 전 준비 비용이 추가될 수 있습니다. 문을 연 뒤 매출이 안정되기 전까지 필요한 운영자금도 따로 계산해야 합니다.

견적서를 받았다는 사실은 비용이 확정됐다는 뜻이 아닙니다. 어떤 작업이 포함됐고 무엇이 빠졌는지, 현장 조건이 달라지면 비용과 일정이 어떻게 바뀌는지를 읽어야 합니다. 합계가 낮은 견적보다 계획한 공사를 같은 조건으로 비교할 수 있는 견적이 판단에 더 도움이 됩니다.

## 현장 장면

두 업체가 비슷한 장비를 제안해도 총액은 다를 수 있습니다. 한 견적에는 운반과 설치, 배관 연결, 전기 작업과 시운전이 들어 있고 다른 견적에는 장비 납품만 포함될 수 있습니다. 철거와 폐기물 처리, 바닥 복구, 배수 연결이 별도라면 처음 보인 금액은 전체 공사비가 아닙니다.

창업자가 각 항목의 차이를 묻지 않고 총액만 비교하면, 공사가 시작된 뒤 빠진 작업이 드러날 수 있습니다. 그때는 공정을 멈출 수 없어 추가 견적을 받아들이거나, 일정이 밀려 임대료와 개업 준비 비용을 더 부담할 수도 있습니다. 그래서 견적은 가격표가 아니라 작업 범위와 책임을 확인하는 문서로 읽어야 합니다.

## 저자의 한 문장

> 견적서에서 먼저 볼 것은 합계가 아니라, 그 금액으로 어디까지 완성되는가이다.

## 경험에서 얻은 판단

창업에 필요한 자금은 한 덩어리로 보지 말고 목적에 따라 나누어 계산합니다.

### 1. 임대와 계약에 들어가는 돈

- 임대 보증금과 계약 시 지급하는 금액

- 중개·계약 관련 비용

- 임대료 선납 여부와 관리비

- 계약 기간, 갱신 조건, 원상복구 비용

- 영업 준비 기간 중에도 발생하는 임대료와 공과금

보증금도 처음에 필요한 현금에 포함하되, 비용으로 소모되는 돈과 구분해 기록합니다. 보증금의 일부로 낸 계약금은 보증금 총액에 다시 더하지 않습니다. 선납 임대료도 같은 기간의 운영자금에 중복 반영하지 않습니다. 보증금의 회수 가능 여부와 시점은 계약 조건으로 확인합니다.

### 2. 건물·기반 공사비

- 철거와 폐기물 처리

- 바닥 절단·정리·구배·방수·재시공

- 급수·배수·집수·배관 연결

- 폐수 관련 시설과 필요한 연결·보수

- 전기 인입·배선·분전·차단·접지

- 조명·환기·간판·출입구 등 부대 시설

- 설계·현장 조사·각종 협의나 검사에 필요한 비용

- 공사 중 추가로 발생할 수 있는 작업

기존 시설을 활용하는 경우에도 실제 작동 상태와 사용 가능 여부를 확인해야 합니다. “이미 설치돼 있다”는 말만으로 수리나 교체 비용이 필요 없다고 가정하지 않습니다.

### 3. 장비와 설치비

- 장비 본체와 옵션

- 운송·상하차·현장 반입

- 설치·고정·배관·전기 연결

- 시운전과 작업자 교육

- 소모품·초기 약품·타월 등 개업 재고

- 보증 범위 밖의 출장비와 유지관리 조건

- 장비별 예비품 또는 대체 장비

장비 가격을 비교할 때 모델명·사양·수량·옵션을 맞춰야 합니다. 이름만 같은 장비라도 모터, 압력, 재질, 제어 방식, 설치 조건이 다르면 단순 비교가 어렵습니다.

### 4. 개업 준비비

- 사업장 정리와 청소

- 가격표·안내판·고객 응대 준비물

- 예약·결제 수단과 통신 환경

- 직원 채용과 교육

- 유니폼·안전용품

- 개업 전 시운전과 테스트에 필요한 재료

- 홍보와 오픈 안내 비용

### 5. 운영자금과 생활비

- 임대료와 관리비

- 급여와 사업주가 실제로 부담할 인건비 관련 비용

- 공과금·통신비·보험료

- 세제와 소모품

- 장비 점검·수리비

- 세금과 금융비용

- 매출이 예상보다 늦을 때의 운영자금

- 가정의 생활비와 개인 대출 상환액

사업자금과 가정 생활비를 구분해야 합니다. 사업장 계좌에 돈이 남아 있다고 해서 모두 투자에 쓸 수 있는 돈은 아닙니다. 가족 생활비와 대출 상환이 사업 매출에 기대고 있다면, 그 금액도 매월 필요한 현금으로 반영해야 합니다.

## 직접 대입하는 창업자금 계산

아래 표에 실제 견적과 계약 조건을 넣어 봅니다. 모든 금액은 같은 기준으로 적고, 부가세 포함 여부를 표시합니다. 보증금처럼 회수 가능성이 있는 금액은 지출 항목과 별도 표기합니다.

| 구분 | 내 견적 금액 | 부가세 포함 여부 | 확인 자료 |
| --- | ---: | --- | --- |
| 보증금 |  |  | 임대차계약서 |
| 계약·중개·선납 임대료 |  |  | 계약 조건 |
| 철거·폐기물 |  |  | 공사 견적서 |
| 바닥·배수·급수 공사 |  |  | 도면·공사 견적서 |
| 폐수 관련 시설·공사 |  |  | 관할 확인·업체 견적 |
| 전기·조명·환기 |  |  | 장비 목록·전기 견적 |
| 장비 본체·옵션 |  |  | 모델·사양 견적 |
| 운반·설치·시운전 |  |  | 설치 범위 확인서 |
| 인허가·설계·검토 비용 |  |  | 기관·전문가 확인 |
| 개업 준비·초기 재고 |  |  | 구매 목록 |
| 예비비 |  |  | 산정 근거 |
| 운영자금 |  |  | 월별 지출 계획 |
| **총 필요 현금** |  |  | 위 항목 합계 |

총 필요 현금은 사업 개시 전 지출과 일정 기간 운영에 필요한 현금을 합해 봅니다. 예비비와 운영자금은 중복 계산하지 않도록 용도를 구분합니다.

예시로 계산 방법만 보겠습니다. 아래 숫자는 특정 세차장의 실제 견적이나 평균 비용이 아니라 계산 구조를 보여주기 위한 임의의 예시입니다.

- 임대 보증금: 2,000만 원

- 계약·선납 비용: 500만 원

- 공사비: 4,000만 원

- 장비와 설치비: 3,000만 원

- 개업 준비비: 500만 원

- 예비비: 1,000만 원

- 운영자금: 2,000만 원

이 경우 준비해야 할 현금은 **1억 3,000만 원**입니다. 여기서 보증금은 계약 조건에 따라 회수될 수 있는 자금이고, 나머지는 지출되거나 운영에 사용되는 돈입니다. 실제 계산에서는 각 항목을 본인 계약서와 견적서, 월별 비용으로 바꾸어야 합니다. 부가세 처리와 대출 실행 시점, 보증금 회수 조건도 별도로 확인합니다.

## 예비비와 운영자금을 나누는 법

예비비는 공사나 설치 중 확인하지 못한 조건이 드러날 때 대응하기 위한 돈입니다. 운영자금은 개업 후 매출이 비용을 따라잡기 전까지 사업을 유지하는 돈입니다. 둘을 같은 항목처럼 쓰면 공사 추가 비용으로 운영자금이 사라질 수 있습니다.

운영자금은 “몇 달치가 적당하다”는 단일 숫자로 정하기 어렵습니다. 자신의 월별 고정비와 변동비, 매출이 늘어나는 속도, 대출 상환액, 개인 생활비를 기준으로 여러 경우를 계산합니다.

### 월별 운영자금 계산표

| 월 지출 항목 | 예상 금액 | 실제 또는 근거 |
| --- | ---: | --- |
| 임대료·관리비 |  | 계약서 |
| 인건비와 관련 비용 |  | 인원·근무시간 계획 |
| 공과금·통신 |  | 예상 사용량·요금 |
| 세제·소모품 |  | 작업량별 사용 계획 |
| 수리·유지관리 |  | 장비와 업체 조건 |
| 세금·보험·금융비용 |  | 세무·금융 자료 |
| 기타 사업 지출 |  | 항목별 근거 |
| **월 운영비 합계** |  |  |

예상 매출이 낮은 경우에도 이 지출을 감당할 수 있는지 확인합니다. 사업 운영자금과 가정 생활비를 한 계좌에서 함께 사용한다면, 각각의 사용액을 따로 적어 실제로 얼마나 버틸 수 있는지 계산해야 합니다.

## 견적서 읽기 점검표

견적서마다 아래 항목에 답할 수 있어야 비교가 가능합니다.

### 장비 견적

- 모델명·수량·사양·옵션이 정확히 적혀 있는가?

- 납품과 설치가 각각 포함됐는가?

- 운반·상하차·현장 반입 비용이 포함됐는가?

- 배관·전기 연결의 시작점과 끝점이 명시됐는가?

- 시운전, 교육, 사용설명서, 보증 범위가 적혀 있는가?

- 추가 부품과 소모품의 가격·공급 조건이 확인되는가?

### 공사 견적

- 철거·폐기물·바닥·배수·급수·전기·환기 범위가 구분되어 있는가?

- 기존 시설을 재사용하는 항목은 작동 확인과 책임 주체가 적혀 있는가?

- 도면과 현장 조건이 견적의 기준으로 첨부되어 있는가?

- 포함하지 않는 항목과 별도 발주 항목이 적혀 있는가?

- 예상 외 작업이 생기면 누가 어떤 근거로 추가 견적을 내는가?

- 추가 공사를 시작하기 전에 누가 승인하는가?

- 공사 일정, 중단 조건, 하자 보수 기간이 있는가?

### 모든 견적 공통

- 공급가액과 부가세, 총액이 구분되어 있는가?

- 지급 일정과 계약금·중도금·잔금 조건이 명확한가?

- 견적 유효 기간과 가격 변동 조건이 있는가?

- 작업 완료를 확인할 기준이 있는가?

- 미완료·불량·재작업이 있을 때 처리 절차가 적혀 있는가?

- 구두로 합의한 내용이 견적서나 계약서에 반영되었는가?

## 저자 현장 사례를 보태기 위한 질문

1. 장비 가격만 비교했다가 설치·공사 범위 차이로 총비용이 달라진 사례가 있었습니까?

2. 견적서에서 빠져 창업자가 특히 난처해지는 비용 항목은 무엇입니까?

3. 예비비나 운영자금을 충분히 두지 않아 개업 직후 어려움을 겪는 현장을 보셨습니까? 어떤 지출이 예상보다 빨리 발생했습니까?

## 이 단원 요약

- 창업비용은 임대, 공사, 장비, 개업 준비, 운영자금으로 나누어 계산합니다.

- 예비비와 운영자금은 따로 잡습니다.

- 견적은 같은 기준으로 비교하고, 빠진 항목을 업체에 묻습니다.

## 다음 단원으로

필요한 자금과 견적 범위를 파악했다면, 다음에는 실제 운영 방식에 맞는 장비를 선택하고 설치해야 합니다. 다음 단원에서는 장비의 기능을 나열하는 데 그치지 않고, 작업량·동선·설치 환경에 맞는 사양을 고르고 시운전 결과를 확인하는 기준을 다루겠습니다.
