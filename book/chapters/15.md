# 15단원 오래 운영하는 사업주가 점검할 것

## 시작하며

매장이 자리를 잡으면 매일 작업을 처리하느라 장기적인 숫자를 놓치기 쉽습니다. 매출이 늘어도 비용과 미수금, 대출 상환, 장비 교체비가 함께 늘면 실제로 쓸 수 있는 돈은 부족할 수 있습니다. 오래 운영한다는 것은 오래 버티기만 하는 일이 아니라, 현장을 안전하고 일정한 품질로 유지하면서 사업에 들어오고 나가는 돈을 확인하고 필요한 곳에 다시 투자하는 일입니다.

## 매출과 남는 돈은 다르다

매출에서 재료비와 결제 수수료, 임대료, 인건비, 공과금, 보험료, 수리비, 이자와 세금 등이 나갑니다. 사업주가 가져가는 돈과 사업에 남겨야 할 돈도 구분해야 합니다. 월말에는 다음을 나눠 확인합니다.

- 매출: 서비스별 판매 금액과 실제 입금액

- 변동비: 세제·타월 세탁·소모품·결제 수수료 등

- 고정비: 임대료·정기 인건비·통신비 등

- 금융 부담: 원금 상환·이자·리스료

- 세금과 공과금: 납부 시기와 금액

- 사업주 생활비와 예비·장비 교체 자금

회계 처리와 세무 신고는 사업 형태와 계약에 따라 달라질 수 있으므로 세무 전문가와 확인합니다. 여기서는 운영 판단을 위한 관리 숫자를 다룹니다.

## 서비스별로 매출 흐름을 본다

월 총매출만 보면 어떤 서비스가 매장을 지탱하는지 알기 어렵습니다. 서비스별 건수와 평균 판매 금액, 작업 시간, 변동비를 함께 기록합니다.

| 서비스 | 월 작업 건수 | 평균 판매가 | 평균 작업 시간 | 건당 변동비 | 건당 공헌이익 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 기본 손세차 |  |  |  |  |  |
| 실내 세차 |  |  |  |  |  |
| 추가 서비스 |  |  |  |  |  |

**건당 공헌이익 = 실제 판매가 − 해당 작업의 변동비**

인건비는 지급 방식에 따라 분류합니다. 작업량과 관계없이 지급하는 월급은 고정비에, 작업 증가에 따라 추가 발생하는 건별 인건비는 변동비에 넣습니다. 9단원처럼 가격 검토를 위해 월급이나 사업주 노동을 건당 배분했다면, 월 손익 계산 때 같은 금액을 고정비에 다시 더하지 않습니다. 사업주의 가정 보수와 실제 현금 인출도 구분해 기록합니다.

예시로, 정기 인건비는 고정비에 포함하고 추가 건별 인건비는 없다고 가정합니다. 판매가가 6만 원이고 직접 들어간 소모품·수수료가 8천 원이면 건당 공헌이익은 5만 2천 원입니다. 이 금액이 순이익은 아닙니다. 임대료·인건비·공과금 등 매장 유지 비용을 아직 부담해야 합니다. 서비스별 작업 시간이 다르면 한 시간당 공헌이익도 비교하되, 품질과 안전을 낮춰서는 안 됩니다.

## 손익분기점을 운영 기준으로 사용한다

**월 손익분기 매출 = 월 고정비 ÷ 공헌이익률**  
**공헌이익률 = (매출 − 변동비) ÷ 매출**

월 고정비를 900만 원, 평균 공헌이익률을 65%라고 가정하면 월 손익분기 매출은 약 1,385만 원입니다. 이는 계산 예시입니다. 실제 의사결정에는 자기 매장의 비용 자료와 상환 일정, 사업주의 최소 보수 기준을 넣어야 합니다.

공헌이익률이 양수일 때 사용하는 식입니다. 월 손익분기 매출을 영업일 수로 나누면 하루 필요 매출, 이를 같은 판매 구성의 평균 객단가로 나누면 하루 필요 작업 대수가 됩니다. 정수 대수로 계획할 때는 올림합니다. 필요한 작업량이 실제 작업 시간과 인력으로 불가능하다면 매출 목표나 비용 구조를 다시 검토해야 합니다.

## 통장 잔액과 현금 흐름을 확인한다

장부상 이익이 나더라도 입금과 지출 시점이 다르면 현금이 부족할 수 있습니다. 매달 앞으로 8~13주 동안 예정된 입금과 지출을 주 단위로 정리합니다.

| 주차 | 예상 입금 | 임대·급여 | 공과금·재료 | 상환·세금 | 수리·투자 | 예상 잔액 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 1주 |  |  |  |  |  |  |
| 2주 |  |  |  |  |  |  |
| 3주 |  |  |  |  |  |  |
| 4주 |  |  |  |  |  |  |

확정 입금과 지연 가능성이 있는 매출을 구분합니다. 세금이나 보험료처럼 특정 시기에 큰 금액이 나가는 항목은 미리 준비합니다. 잔액 부족이 예상되면 지출 연기나 자금 조달을 미리 검토하고, 대출·상환 변경은 비용과 약정 조건을 확인해 전문가와 상의합니다.

## 장비·시설 재투자 우선순위

모든 장비를 새것으로 바꾸는 것이 좋은 운영은 아닙니다. 반대로 고장을 방치하면 작업 지연, 고객 불편, 안전 위험과 추가 수리비가 커질 수 있습니다. 판단할 때 다음을 비교합니다.

- 최근 1년간 수리 횟수와 총비용

- 고장으로 발생한 영업 중단 시간과 놓친 작업

- 안전·위생·품질에 미치는 영향

- 수리 후 기대 사용 기간과 보증

- 교체 가격 외 철거·설치·배관·전기 공사 비용

- 교체 중 영업을 유지할 수 있는지

- 작업 시간과 인력 부담의 변화

- 투자금이 운영자금과 세금 준비금을 침해하는지

투자는 새 제품이 좋아 보인다는 이유보다, 사업의 병목을 줄이고 고객 약속과 안전을 지키는 데 필요한지로 평가합니다. 견적서에는 설치 범위, 기존 시설 변경, 교육, 보증과 사후 대응 조건까지 확인합니다.

## 매달 보는 현장 지표

매달 같은 기준으로 기록하고 갑작스러운 변화가 있으면 원인을 찾습니다.

- 서비스별 작업 건수와 매출

- 평균 객단가와 추가 서비스 선택률

- 예약 취소·대기 시간

- 서비스별 실제 작업 시간

- 재작업·환불·고객 불만 건수

- 장비 고장 횟수와 영업 중단 시간

- 소모품 사용량과 재고 부족

- 인건비와 작업량 변화

- 재방문 고객 비율(측정 기준을 동일하게 유지)

- 미수금과 향후 8~13주 예상 잔액

지표가 나빠졌을 때 곧바로 직원이나 고객 탓으로 돌리지 않습니다. 날씨·계절·영업일·가격 변경·예약 방식·작업 범위·장비 상태를 함께 봅니다. 매달 정의와 수집 방법을 같게 유지해야 비교할 수 있습니다.

## 분기마다 운영 구조를 점검한다

1. 어떤 서비스가 매출과 공헌이익에 가장 크게 기여했는가?

2. 작업 시간 대비 수익이 낮거나 재작업이 잦은 서비스가 있는가?

3. 고객 불만은 작업 범위, 대기, 결과 안내 중 어디에서 반복되는가?

4. 한 사람에게만 의존하는 업무는 무엇인가?

5. 반복 고장과 임시 수리가 늘어난 장비가 있는가?

6. 다음 분기의 세금·상환·수선 지출을 준비했는가?

7. 가격이나 운영 시간을 바꿀 근거가 충분한가?

8. 사업주가 현장에 붙어 있어야만 매장이 유지되는가?

한 번에 큰 변화를 주기보다 목적, 예상 효과, 비용, 확인 날짜를 적습니다. 예약 간격을 바꿨다면 지연률과 대기, 하루 작업 수를 일정 기간 비교한 뒤 유지 여부를 결정합니다.

## 사업주가 지켜야 할 운영 원칙

- 매출과 통장 잔액을 같은 뜻으로 보지 않습니다.

- 사업 운영자금과 개인 생활비의 흐름을 기록합니다.

- 손익분기점은 실제 비용 자료로 갱신합니다.

- 세금·상환·수선비를 별도로 준비합니다.

- 안전과 고객 약속을 단기 매출과 맞바꾸지 않습니다.

- 책임을 맡길 때 필요한 권한과 교육도 제공합니다.

- 기록에 근거해 가격·인력·투자를 조정하고 결과를 확인합니다.

- 법률·세무·노무·시설 기준은 전문가와 관할 기관에 확인합니다.

2. 고장 장비를 반복 수리하다 교체한 경우 실제 결정 기준은 무엇이었습니까?

3. 오래 운영한 사업주가 매출 외에 꾸준히 확인하는 숫자나 습관은 무엇입니까?

4. 사업주가 현장을 비워도 운영되는 매장에는 어떤 역할 분담과 기록이 있었습니까?

## 이 단원 요약

- 매출과 남는 돈, 통장 잔액을 따로 확인합니다.

- 장비·시설 재투자는 우선순위를 정해 결정합니다.

- 매달 현장 지표를 보고 분기마다 운영 구조를 점검합니다.

## 맺으며

세차장 운영은 한 번의 큰 결심보다 매일의 점검과 수정으로 이어집니다. 계약 전에는 입지와 시설을 확인하고, 개업 전에는 흐름을 시험하고, 영업 중에는 숫자와 현장을 함께 살펴야 합니다. 책의 예시를 정답처럼 쓰기보다 자기 매장의 기록으로 채우십시오. 직접 확인한 사실과 아직 확인하지 못한 가정을 구분하는 것부터 안정적인 운영이 시작됩니다.
