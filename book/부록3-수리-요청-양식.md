# 부록 3. 수리 요청 양식

```text
사업장과 담당자:
장비명·모델명·제조번호:
설치일 또는 사용 기간:
증상 최초 발생 시각:
어떤 작업 중 발생했는지:
정상 상태와 달라진 점:
소리·냄새·누수·계기 표시:
전원 또는 압력 차단 여부:
최근 수리·부품 교체 이력:
현재 사용 중지 여부:
사진·영상:
영업에 미치는 영향과 희망 방문 시간:
```

**견적 받을 때 확인할 것:** 출장비·진단비·부품비·공임 구분, 수리 전 원인과 예상 총액, 추가 작업은 사전 승인, 교체 부품과 작업 내용 기록, 수리 후 시험 결과와 보증 범위.
