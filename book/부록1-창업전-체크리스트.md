# 부록 1. 창업 전 체크리스트

관련 단원을 함께 보십시오. 법령·지자체 기준은 관할 기관 확인이 필요합니다.

**나와 가족 (2~3단원)**
- [ ] 창업 동기와 원하는 생활을 글로 적었다.
- [ ] 가족과 역할, 생활비, 버틸 기간을 합의했다.
- [ ] 생활비와 사업자금을 나누어 계산했다.

**입지와 계약 (4단원)**
- [ ] 차량 흐름과 진입·대기·출고 동선을 현장에서 확인했다.
- [ ] 건축물 상태, 용도, 공사 가능 여부를 관할 부서에 확인하고 기록을 남겼다.
- [ ] 확인 결과와 책임 조건을 계약서에 반영하고 전문가 검토를 받았다.

**시설 (5단원)**
- [ ] 급수, 배수, 빗물 경로를 확인했다.
- [ ] 세차 물의 처리 방식과 필요한 시설·신고·협의를 관할 기관에 확인했다.
- [ ] 전기 용량과 장비 설치 조건을 확인했다.

**돈 (6, 9, 10단원)**
- [ ] 창업비용을 항목별로 나누고 예비비와 운영자금을 따로 잡았다.
- [ ] 견적서를 같은 기준으로 비교하고 빠진 항목을 물었다.
- [ ] 서비스별 남는 돈과 손익분기점을 내 숫자로 계산했다.

**장비 (7~8단원)**
- [ ] 설치 범위와 시운전 인수 기준을 글로 합의했다.
- [ ] 보증 기간, 수리 연락처, 대응 시간을 확인했다.

**사업자와 보험, 세무**
- [ ] 사업자 등록 절차와 필요 서류를 확인했다. (확인 필요)
- [ ] 차량 손상 등에 대비한 보험 가입 여부와 보장 범위를 보험사에 확인했다. (확인 필요)
- [ ] 세무 신고 방식과 기장 방법을 세무 전문가와 상의했다. (확인 필요)
- [ ] 직원을 둔다면 근로계약과 근로조건을 관련 법령에 맞게 준비했다. (확인 필요)

**오픈 (14단원)**
- [ ] 실제 차량으로 접수부터 출고까지 전체 과정을 시험했다.
- [ ] 직원이 전원 차단 위치와 비상 정지 방법을 알고 있다.
